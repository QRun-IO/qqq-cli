# UI API server findings from the terminal clients

Observed while building the CLI and TUI against QQQ 4.1.0-SNAPSHOT (`develop` 6ac64fc66, UI API 1.8.0) with
the sample app and MOCK authentication. Filed on 2026-10-31 (James's OK); the `Issue` column links each one. Finding 10 was already open as #784, 9 and 21 share #1343, 18 is in qbit-collaboration.
