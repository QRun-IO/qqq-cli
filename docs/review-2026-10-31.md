# CLI and kernel review, 2026-10-31

A fresh read of `packages/core/src` and `packages/cli/src` (generated `schema.ts` and `operations.ts` skipped) after
the five M1 streams were merged onto the 0.1 CLI (`feat/m1-kernel-cli` at f364a3c). Branch `feat/m1-hardening`.
Every finding below was reproduced (against the sample server at :8077, or a test) before it was changed; each fix
has a test (unit test, or a case in the golden suite `packages/cli/src/test/cli.test.ts`).

Severity: **high** = wrong data, lost state or a command that silently does something else; **medium** = wrong exit
code, hidden error or an inconsistency a user meets; **low** = polish.

## Requested additions (coordinator)

- **Download directory.** `qqq config set|get download-dir`, `upload-dir`, `download-prompt`, kept in the `ui`
  section of `~/.config/qqq/config.json` through `readUiSettings`/`writeUiSettings` in `session/profiles.ts` (the
  section and key names the TUI uses: `defaultDownloadDir`, `defaultUploadDir`, `downloadPrompt`). `table download`,
  `table export`, `report run` and process downloads default to it (created when missing) when no `--out` /
  `--out-dir` is given. An explicit `widget get --csv <file>` is written where named (a named path is never moved).
- **`qqq doctor`.** Profile, reachability, UI API version range (1.6.0 to 1.8.0, major from `supportedMajorVersions`),
  authentication type, sign-in accepted, extensions and minimums, keyring, cache age; `--conformance` runs the
  conformance package's read-only checks. Exit 1 lists the failures. The terminal half calls the kernel's
  `checkTerminalEnvironment()` by name (reported as `skip` until the TUI branch's module lands); `--fix` applies its
  fixes after two confirmations.

## Found and left

| Sev | Finding | Why left / suggestion |
|---|---|---|
| medium | The macOS Keychain store passes the secret on `security add-generic-password -w <secret>`'s command line (visible to `ps` for an instant); the DPAPI store does the same with PowerShell. | Needs `security -i` over stdin (quoting) or a native helper; worth a follow-up before GA. |
| medium | The metadata cache is keyed by server, not by profile or user: switching profiles on one server shows the previous user's permission-filtered metadata for up to 5 minutes (a refused token still lists cached tables). | Key the cache by profile, or clear it on login/logout. Touches the cache format the TUI reads. |
| low | `runProcess` returns when it reaches the last frontend step, so a last step with an input form would never be submitted. No sample process has one. | Confirm the server's contract for a final input step before changing it. |
| low | `apps show` and `saved-view list` show `?` for a count that failed, without the reason. | Display-only; acceptable, but could print the error on stderr. |
| low | Remaining short-option overlaps without a collision: `-o` is `--order` on queries and `--out` on download/report/api; `-f` is `--fields` and `job logs --follow`; `-i` is `--interactive` and `widget get --input`. | No command has both meanings; renaming would break documented usage. |
| low | `collab presence --watch` exits 0 on Ctrl-C while `tail` exits 130. | Presence leaves its lease cleanly, so 0 is defensible; align if `tail`'s 130 is the house rule. |
| info | `qqq doctor --conformance` loads `@qrun-io/qqq-ui-api-conformance` dynamically; it is not a dependency of the CLI package. | Release engineering: add it as a dependency (or optional dependency) of `@qrun-io/qqq-cli`. |
